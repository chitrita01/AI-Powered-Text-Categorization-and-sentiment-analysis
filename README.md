# AI-Powered-Text-Categorization-and-sentiment-analysis
TextClust is an AI-powered machine learning project designed for **text clustering, sentiment analysis, and keyword extraction** using **natural language processing (NLP)** techniques. This project preprocesses textual data by cleaning, tokenizing, and lemmatizing it before generating embeddings via **sentence transformers**. Using **KMeans clustering**, it categorizes texts into meaningful groups and extracts **keyphrases** from clustered data to provide insightful labels. Additionally, it employs **sentiment analysis** to determine whether a text expresses **positive, negative, or neutral emotions**. TextClust is built for adaptability, automatically retraining on newly accumulated data to refine its predictions over time. With support for **batch and single-text inference**, it allows users to efficiently analyze and classify text for various applications, such as **content organization, trend discovery, and automated categorization**. Developed with **Python, PyTorch, Hugging Face Transformers, and NLTK**, this project serves as a robust foundation for AI-driven text analytics and insight generation. Contributions and enhancements are welcome to further optimize clustering accuracy, expand sentiment classification capabilities, and integrate additional NLP-driven insights.
